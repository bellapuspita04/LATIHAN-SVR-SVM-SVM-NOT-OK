Repository ini berisi beberapa project latihan Python yang saya kerjakan untuk mempelajari pengolahan data dan machine learning. Project yang ada di repository ini meliputi analisis dataset diabetes, prediksi gaji berdasarkan pengalaman kerja, dan klasifikasi menggunakan algoritma SVM.

# Daftar Project

# 2. Prediksi Gaji Menggunakan SVR
Mencoba memprediksi gaji berdasarkan lama pengalaman kerja menggunakan metode Support Vector Regression (SVR) dengan kernel RBF.
